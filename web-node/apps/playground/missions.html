Regole d'Oro del Flusso Autonomo:
✓ Nessun commit senza conferma utente: Il codice e gli artefatti prodotti dai nodi vivono in sandbox temporanee fino a esplicita validazione umana.
✓ Gate Verifier Indipendente: Il verdetto di un task non si basa sulle parole del modello ("tutto ok"), ma su test pytest ed evidenze reali di file generati.
✓ Zero Segreti nei Log: Credenziali, token di bot e chiavi API non vengono mai registrati nei report né stampati nei flussi broadcast.
✓ Resilienza al Riavvio: Gli scheduler persistono i checkpoint su disco in formato JSONL idempotente; un riavvio continua il task interrotto senza doppie esecuzioni.
